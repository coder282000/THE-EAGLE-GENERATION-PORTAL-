# SCREEN SPEC: [ADM-112] Financial Reporting and Export

## 1. Identification
- Screen ID: ADM-112
- Route: /admin/finance/reports
- Layer: Admin Console
- Module: Commerce and Finance
- Release: R3
- Priority: P0
- Related requirements: FR-8.8 (settlement reports, exports), FR-10.5,
  RO-9 (7-year retention)
- Related panel: PNL-09
- Related gates: G-4

## 2. Purpose
Produce the periodic financial reports the Finance Officer needs and the
exports that feed the accounting system. Every figure here is derived from
the ledger, not from re-computed transaction totals. The export is the
boundary between the platform and whatever tool the Finance Officer uses
for statutory accounts.

Reports are version-stamped and watermarked with the producing user. Every
export is audited.

## 4. Entry and exit points
- Reached from: sidebar (Finance > Reports), ADM-104 settlement close,
  ADM-105 month-end, ADM-110 drill
- Leads to: report preview, PDF download, CSV download, export history
- Deep-linkable: yes. URL params: ?report, ?from, ?to, ?run

## 5. Layout and regions
- Page header: title, subtitle, "Generate report" action
- KPI row: four cards
  - Reports available (n)
  - Runs this month (n)
  - Last run at (relative time)
  - Most recent export (date)
- Tabs: Available reports / Recent runs
- Available reports tab
  - Grid of report cards: name, description, typical period, format,
    last run
  - Each card has "Preview", "Generate PDF", "Generate CSV"
- Recent runs tab
  - Data table: report, period, generated by, generated at, format,
    download links, status
- Row click on a recent run opens a side panel with the preview and
  download options

## 8. Actions
| Action | Trigger | Permission | Confirmation | API call | Audited |
|---|---|---|---|---|---|
| Preview report | Report card | FINANCE+ | No | GET /finance/reports/:key/preview | No |
| Generate report | Report card | FINANCE+ | Yes | POST /finance/reports/:key/runs | Yes |
| Download PDF | Run row | FINANCE+ | No | GET /finance/reports/runs/:id.pdf | Yes |
| Download CSV | Run row | FINANCE+ | No | GET /finance/reports/runs/:id.csv | Yes |
| Regenerate | Run row | FINANCE+ | Yes | POST /finance/reports/runs/:id/regenerate | Yes |
| Delete run | Run row | SUPER_ADMIN | Yes (typed) | DELETE /finance/reports/runs/:id | Yes |
| Export run history | Toolbar | FINANCE+ | No | GET /finance/reports/runs.csv | Yes |

Report runs are retained for 7 years, aligned with the retention rule for
financial records. Deleting a run is a soft delete and is only available
for runs younger than 30 days.

## 9. States
- Empty (no runs): "No reports generated yet. Pick a report above."
- Loading: skeleton cards and rows.
- Populated: full dashboard with available reports and recent runs.
- Populated extreme: pagination caps at 50 runs.
- Partial: if a report's underlying data fails, its card shows an inline
  retry; other reports stay usable.
- Error: full-page error card with Retry.
- Permission denied: 403 card for CHAPTER_LEADER and non-finance roles.
  ADMIN sees available reports and runs but download actions are disabled.
- Offline: cached list visible; generation and downloads disabled.
- Success: toast confirms; new run appears at the top of recent runs.
- Destructive confirmation: regenerate, delete run.

## 10. Validation and error handling
- Period must have from <= to. Max range 24 months.
- A report cannot be generated twice for the same key and identical period
  within 5 minutes (prevents accidental double-clicks).
- If a report's underlying ledger verification failed in the period, the
  report is blocked with "Ledger imbalance detected in period. Resolve
  before generating."
- All amounts in reports are integer minor units with explicit currency.
  CSV exports include both the minor-unit integer and the formatted amount.
- Exports are watermarked with actor, report key, period, timestamp,
  and the report run id.

## 12. Accessibility
- Report cards are keyboard-focusable with visible focus ring
- Data table uses `<caption>` and `<th scope="col">`
- Report preview uses `<article>` with `<header>` and sectioned content
- Money values read with currency
- Confirmation dialogs are focus traps
- Focus order: header, KPIs, tabs, report grid or runs table, panel

## 13. Performance
- Payload budget: 250 KB
- Report generation is a background job; the UI shows "Generating..." with
  a polling loop until READY or FAILED
- PDF and CSV exports stream server-side
- Preview is cached for 5 minutes per report key and period
- Recent runs table paginated at 50
