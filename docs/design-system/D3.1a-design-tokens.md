## 1. Purpose

Defines the atomic design tokens for the Eagle Generation Portal.
Every component references these tokens. No hardcoded hex, px, or
font values exist in application code.

Tokens live in two files:

| File | Contents |
|------|----------|
| `styles/tokens.css` | CSS custom properties — colour, motion. Light + dark. |
| `tailwind.config.js` | Tailwind theme extensions — brand scales, semantic aliases, elevation, radii, z-index, breakpoints |

Both are versioned in git. Changes require a change request per §11 of
the Developer Instructions.

## 2. Colour

### 2.1 Brand scales

Five brand scales, defined in `tailwind.config.js`:

| Token | Purpose | Default |
|-------|---------|---------|
| `ink` | Base dark, text, primary surfaces | `#141B2E` |
| `sky` | Secondary brand, primary actions | `#3B5985` |
| `dawn` | Amber accent, hero surfaces | `#E29B3D` |
| `clay` | Alerts, destructive, high priority | `#B8493D` |
| `paper` | Page background, recessed surfaces | `#F3F5F8` |

### 2.2 Semantic layer

Application code **must** use semantic tokens, not raw scales.

| Semantic class | Light | Dark | Use |
|----------------|-------|------|-----|
| `bg-paper` | `#F3F5F8` | `#0D1220` | Page background |
| `bg-paper-muted` | `#E7E9ED` | `#141B2E` | Recessed panels |
| `bg-paper-elevated` | `#FFFFFF` | `#1B2135` | Cards, modals |
| `text-fg` | `#141B2E` | `#F4F5F7` | Primary text |

## 3. Typography

Font stack (via `next/font` in `app/layout.tsx`):

- **Display** — Space Grotesk (`--font-space-grotesk`)
- **Body** — Inter (`--font-inter`)
- **Mono** — IBM Plex Mono (`--font-plex-mono`)

Tailwind classes: `font-display`, `font-body`, `font-mono`.
`font-sans` is aliased to `font-body`.

Money figures use `tabular-nums` (Charter §10).

---

## 4. Spacing

Base unit 4px. Tailwind defaults. One custom: `space-13` = 52px.

---

## 5. Radii

Tailwind defaults with `rounded-md` = 8px. `rounded-lg` = 8px, `rounded-xl` = 12px.

---

## 6. Elevation

Custom shadow scale: `shadow-xs`, `shadow-sm`, `shadow-md`, `shadow-lg`, `shadow-xl`, `shadow-focus`.

---

## 7. Motion

| Token | Value |
|-------|------:|
| `duration-fast` | 120ms |
| `duration-default` | 200ms |
| `duration-slow` | 300ms |

`prefers-reduced-motion: reduce` collapses all durations to 0ms.

## 9. Z-index

`z-dropdown` (10) · `z-sticky` (20) · `z-banner` (30) · `z-overlay` (40) · `z-modal` (50) · `z-popover` (60) · `z-tooltip` (70) · `z-toast` (80).

---

## 10. Rules

1. No hardcoded colours, sizes, or fonts in components.
2. No arbitrary values (`text-[17px]`, `p-[13px]`, `bg-[#abc123]`).
3. Money is `tabular-nums` and integer minor units.
4. Dark mode is class-based (`<html class="dark">`).
5. Reduced motion respected.
6. Focus rings use `shadow-focus`.
